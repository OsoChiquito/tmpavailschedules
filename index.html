This is the TPS Schedule Apps Script that reads the Whiteboard. The board asks it for mode=full, which returns every day it has cached along with the roster. It refreshes itself every 15 minutes, so reloading more often than that will return the same data.

Open the address above with ?mode=full in a browser tab and paste what comes back. Useful when the network blocks the fetch but not the browser.
